## 2024-05-18 - Prevent timing attacks on PIN validation
**Vulnerability:** The `/api/auth` and `/api/admin/auth` endpoints in `app.py` used standard equality operators (`!=`) to validate the `ADMIN_PIN`. This exposes the application to timing attacks where an attacker could deduce the PIN character by character based on response times.
**Learning:** Standard string comparison (`==` or `!=`) returns early when a mismatch is found, meaning the execution time varies depending on how many characters match the secret. This pattern existed because standard equality operators are the default way developers compare strings, overlooking the security implications for sensitive tokens.
**Prevention:** Always use constant-time comparison functions like `hmac.compare_digest` for validating sensitive strings such as passwords, PINs, or authentication tokens. Ensure both arguments are encoded to bytes (`.encode('utf-8')`) and include null checks prior to comparison to prevent exceptions.
