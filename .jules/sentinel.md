## 2024-06-29 - Fix path traversal string matching vulnerability
**Vulnerability:** Path traversal (CWE-22) string comparison bypass. When enforcing directory containment, `str(target).startswith(str(base_dir))` was used. This can be bypassed by an attacker requesting a directory that shares the same prefix but is outside the base directory. For example, if `base_dir` is `/app/reports`, requesting a file from `/app/reports_sneaky/file.txt` would bypass the check because the string `/app/reports_sneaky/file.txt` starts with `/app/reports`.
**Learning:** String `startswith` comparison is fundamentally flawed for path containment verification because it does not consider path boundaries (e.g., slash `/`). This allows attackers to access parallel directories that share the string prefix.
**Prevention:** Always use `pathlib.Path.is_relative_to()` or `os.path.commonpath()` for path containment checks. `is_relative_to` correctly compares path segments rather than raw strings, ensuring the target path is strictly a descendant of the base directory.
